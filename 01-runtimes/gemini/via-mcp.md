If your Gemini-based runtime speaks MCP, this is the easy path.

## What this page will cover

1. **Install.** Add `@opvs-ai/mcp` (or scoped packages) to the runtime's MCP config.
2. **Authenticate.** `OPVS_PAT` brand-scoped, same as every other MCP runtime.
3. **Call a tool.** Marketplace tools appear natively.
4. **Maintenance.** `npx -y` semantics.
5. **Sample code.** Runnable example.
